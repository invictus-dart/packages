## 1.0.0-dev.0

- Initial development prerelease of the Mars Dart bindings.
- Vendored Tencent/mars `release/2024-t3.1` (`a8c6c7d3`) is compiled through
  Dart native assets build hooks (`hook/build.dart` / `hook/link.dart`) into a
  single dynamic library per platform — Android, iOS, macOS, Windows, Linux.
- Third-party dependencies are built from official source tarballs: OpenSSL
  3.5.9 (latest LTS, upgraded from upstream 1.1.1l) and zstd 1.5.7 (upgraded
  from upstream 1.4.4).
- XLog API (`lib/src/xlog.dart`):
  - `open` / `close` lifecycle with async or sync appender mode.
  - Level-filtered logging helpers (`verbose` … `fatal`) with tags and
    automatic file/line/caller capture from Dart stack traces.
  - Blocking `flushSync` / `decodeSync` on the calling thread, with
    isolate-based `flush` / `decode` wrappers that do not block the caller.
  - Compression (zlib / zstd, level 1–9), ECDH public-key log encryption,
    rotation by file size and alive duration, and console mirroring.
  - Offline `decode` of `.xlog` files back to plaintext, with optional ECDH
    private key for encrypted segments.
- FFI bindings generated by `ffigen` from the `src/mars.h` bridge; the bridge
  is the single entry point between Dart and the native library.
- Note: this is a prerelease — the API surface may change in breaking ways
  before 1.0.0.
