## 1.0.0-dev.0

- Initial development prerelease of the zstd bindings.
- zstd 1.5.7 is downloaded from the official release tarball (SHA-256 verified)
  and compiled through Dart native assets build hooks
  (`hook/build.dart` / `hook/link.dart`); no system zstd installation is used.
- `Codec`-compatible API: the shared `zstd` instance, `ZstdCodec`,
  `ZstdEncoder`, and `ZstdDecoder`, each accepting a compression level and an
  optional pre-shared dictionary, plus `RawZstdFilter` for chunked low-level
  compression and decompression.
- Compression levels are validated against `ZstdOption` (`minLevel`,
  `maxLevel`, `defaultLevel`), and native failures raise `ZstdError` with the
  libzstd error code and name.
- Static linking with symbol tree-shaking by default; the `tree_shake` user
  define turns it off and keeps the whole library.
- FFI bindings generated by `ffigen` from the vendored headers in
  `src/include/`, with a `record_use` mapping used for tree-shaking.
- Supported targets: Android, iOS, macOS, Linux, and Windows.
- Note: this is a prerelease — the API surface may change in breaking ways
  before 1.0.0.
